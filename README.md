\## 📚 Overview



\*\*eTutionBD\*\* is a comprehensive online tutoring platform designed to connect students with qualified tutors across Bangladesh. The platform facilitates seamless virtual learning experiences with features like live classes, resource sharing, and progress tracking.



🌐 \*\*Live Demo:\*\* https://etutionbd-af1c0.web.app

\## ✨ Features



\### For Students

\- 🔍 \*\*Find Tutors\*\* - Search and filter tutors by subject, location, and rating

\- 📊 \*\*Progress Tracking\*\* - Monitor learning progress and achievements

\- 💰 \*\*Secure Payments\*\* - Multiple payment options for users



\### For Tutors

\- 👨‍🏫 \*\*Profile Management\*\* - Create and customize teaching profiles

\- 📚 \*\*Course Creation\*\* - Design and manage course content

\- 📈 \*\*Earnings Dashboard\*\* - Track income and payment history



\## 🛠️ Tech Stack



\### Frontend

\- \*\*React.js\*\* - UI library for building interactive interfaces

\- \*\*Tailwind CSS\*\* - Utility-first CSS framework for styling

\- \*\*React Router\*\* - Navigation and routing

\- \*\*Axios\*\* - HTTP client for API requests



\### Backend

\- \*\*Node.js\*\* - JavaScript runtime

\- \*\*Express.js\*\* - Web application framework

\- \*\*MongoDB\*\* - NoSQL database

\- \*\*Firebase\*\* - Authentication and hosting

\- \*\*JWT\*\* - Secure authentication tokens



\### Additional Services

\- \*\*Firebase Authentication\*\* - User authentication

\- \*\*Firebase Hosting\*\* - Web application hosting

\- \*\*Imgbb\*\* - Media storage and optimization

\- \*\*Stripe\*\* - Payment gateway integration



\## 🚀 Installation and Setup



\### Prerequisites

\- Node.js (v14 or higher)

\- npm or yarn

\- MongoDB (local or Atlas)

\- Firebase account
